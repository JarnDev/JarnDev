## About

- 💻 **Backend & full-stack.** Day to day: Node.js, NestJS and Express on the backend; React, Next.js and Astro on the frontend; Python for tooling and automation. Domains I know well: payments & ledgers, event-driven and distributed systems, LLM & graph pipelines, IoT fleets and computer vision.
- 🏠 **Homelab maintainer:** self-hosted Docker stacks, local LLMs (Ollama) on a GPU box, remote access through Cloudflare Tunnel + Tailscale.
- 📚 **Ramping up:** C/C++, CUDA and Rust, through [side projects](https://github.com/users/JarnDev/projects/3).
- 🧠 **Background:** Mechatronics engineering (with an exchange at Tennessee Tech), which led me to Machine Learning and Computer Vision with Python. I'll use or build any tool I can get my hands on to solve a problem.
- 🚴 **Outside the terminal:** cyclist, robotics enthusiast and father.
